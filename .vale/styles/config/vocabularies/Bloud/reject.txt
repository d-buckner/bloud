# error (Vale.Avoid). Use this file for text that is wrong, not merely
# inconsistent: for casing and spelling preferences, add the correct form to
# `accept.txt` instead.

# Vale matches these against whole words, so two forms never fire and are not
# used: an entry that begins with punctuation (`.air.toml`), and an entry whose
# text contains a word accepted in `accept.txt` (an accept entry exempts every
# match containing it, which is why the systemd unit is rejected by its
# distinctive `front\.service` half rather than its full name). Interior
# punctuation needs escaping (`air\.toml`).
